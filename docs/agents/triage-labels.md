# Triage labels

Use the upstream role names as local `Status:` values:

| Role | Meaning |
| --- | --- |
| `needs-triage` | Needs evaluation. |
| `needs-info` | Missing information prevents implementation. |
| `ready-for-agent` | Specified sufficiently for agent implementation. |
| `ready-for-human` | Requires human work. |
| `wontfix` | Deliberately declined. |

For an external tracker, inspect its existing labels before mapping these roles. This configuration does not create or change remote labels.
